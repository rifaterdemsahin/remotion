# 5_Symbols - Video Compositions

This folder contains the consolidated VideoGenerator project, which is the master Remotion project for all video compositions.

## Structure

- **[VideoGenerator](./VideoGenerator)**: Unified Remotion project containing all video compositions
  - All video compositions are organized under `src/compositions/`
  - Single `package.json` and configuration for all videos
  - Eliminates duplication of dependencies and configuration across projects

## Getting Started

```bash
cd VideoGenerator
npm install
npm run dev
```

See the [VideoGenerator README](./VideoGenerator/README.md) for detailed documentation.
