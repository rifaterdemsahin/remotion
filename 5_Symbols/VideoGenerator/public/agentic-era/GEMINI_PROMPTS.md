# Gemini Image Generation Prompts

This document contains all the image generation prompts needed to create the visual assets for the "Agentic Era" video composition.

## Usage Instructions

1. Go to Google AI Studio or use Gemini API
2. Copy each prompt below
3. Generate the image with specifications: 1920x1080 resolution
4. Save the generated image with the filename specified
5. Place in `/public/agentic-era/images/` directory

## Notes

- All images should use the project color palette defined in `src/utils/constants.ts`
- Images with dark backgrounds should use #0f172a (dark) or #1e293b (darkGray)
- Split-screen images (960x1080) are for side-by-side comparisons
- Full-screen images should be 1920x1080
- Use PNG format for transparency support
- Keep file sizes reasonable (< 2MB per image)
- Consider generating multiple variations and choosing the best

## Alternative: Using Placeholder Images

If you want to test the composition before generating final images, you can:

1. Use solid color placeholders
2. Use free stock images from Unsplash/Pexels
3. Use screenshot mockups from design tools
4. Generate simple geometric patterns

The composition is designed to work with or without images, using strong text and animation.
