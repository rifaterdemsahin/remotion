# Agentic Era Assets

This directory contains all assets for the Agentic Era video composition.

## Directory Structure

```
agentic-era/
├── images/          # Static images and illustrations
├── screenshots/     # Screen recordings and demos
└── audio/          # Background music and voiceover
```

## Notes

- All images should be 1920x1080 (Full HD) unless specified otherwise
- Screen recordings should be 30 FPS
- Audio files should be high quality (320 kbps recommended)
- Use PNG format for images with transparency
- Use MP4 format for video files (H.264 codec)
